## 0.12.0 - 2026-09-25

복구와 스킬 관리 화면을 더 간단하고 안전하게 사용하는 기능 릴리스입니다.

### 주요 변경

- 앱을 실행할 때마다 데이터베이스 백업을 만들지 않고, 스키마 변경 전 백업과 사용자가 요청한 백업을 제공합니다.
- 복구 화면에서 데이터베이스 백업 폴더를 바로 열고, 설치 파일과 휴지통 항목을 접어 볼 수 있습니다.
- 스킬 카드에서 플랫폼 사용 설정과 여러 플랫폼이 함께 쓰는 설치 관리를 구분해 표시합니다.
- 카드의 반복 정보를 줄이고, 제거 작업은 영향을 알 수 있는 별도 메뉴로 옮겼습니다.
- 기기 번역을 다시 시도할 수 있도록 하고 번역 메뉴를 계속 표시합니다.

### 검증

- Vitest, TypeScript, ESLint 통과
- Rust 복구 테스트와 Clippy 통과

## 0.12.0 - 2026-09-25（中文）

本版本让恢复和技能管理界面更简洁、更安全。

- 不再在每次启动时创建数据库备份；改为在数据库结构升级前及用户手动请求时备份。
- 恢复页面可直接打开数据库备份文件夹，并可折叠查看安装备份和回收站项目。
- 在技能卡片中清楚区分平台启用状态与多个平台共用的安装管理。
- 减少重复信息，并将卸载操作移至可查看影响范围的独立菜单。
- 保留翻译菜单，并支持重试设备翻译。
