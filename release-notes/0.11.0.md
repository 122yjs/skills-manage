## 0.11.0 - 2026-09-14

공용 설치를 실제 경로와 링크 관계 기준으로 안전하게 제어하는 기능 릴리스입니다.

### 주요 변경

- 공용 스킬의 확인된 영향 범위와 별도 설치를 표시합니다.
- 공용 설치 비활성화·복원 전에 영향 확인을 요구합니다.
- 재스캔, 충돌, 파일·DB 오류에서도 원본과 플랫폼별 제외 설정을 보존합니다.
- PlatformView와 UniversalInstallView에 동일한 공유 제어 UX를 제공합니다.
- 공용 설치 영향 범위와 복원 흐름의 Rust·Vitest 회귀 테스트를 추가했습니다.

### 검증

- Frontend CI: typecheck, lint, Vitest 통과
- Rust CI: fmt, Clippy, cargo test 통과
- 격리 HOME·SQLite 기반 실제 공유 설치 스모크 통과

## 0.11.0 - 2026-09-14（中文）

这是一个围绕共享安装安全控制的功能版本。

- 按实际路径和链接关系显示共享技能的影响范围与独立安装。
- 停用或恢复共享安装前显示影响确认。
- 扫描、冲突以及文件和数据库失败时保留原始技能与平台排除设置。
- 统一 PlatformView 和 UniversalInstallView 的共享控制体验。
