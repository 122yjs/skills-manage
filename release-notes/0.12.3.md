## 0.12.3 - 2026-09-26

Codex 스킬 설치 대상과 공용 경로 구분을 바로잡은 안정성 패치입니다.

### 수정

- Codex의 대표 전역 스킬 경로를 `~/.codex/skills`로 분리해 '다른 하네스로 이식' 목록에서 누락되지 않게 했습니다.
- Codex 프로젝트 범위는 공식 문서대로 `.agents/skills`를 유지하고, 공용 경로의 스킬은 읽기 전용 호환 출처로 표시합니다.
- 기존 0.12.2의 GitHub 스킬 가져오기·업데이트 실행 권한 보존 변경을 포함합니다.

### 검증

- Frontend, Backend, Graphify CI 통과
- Windows x64, macOS arm64, Linux x64·arm64 패키지 빌드 통과
