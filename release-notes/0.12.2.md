## 0.12.2 - 2026-09-25

스킬을 가져오거나 업데이트할 때 실행 가능한 스크립트 권한을 보존하는 안정성 패치입니다.

### 수정

- GitHub에서 스킬을 가져오거나 업데이트할 때 파일의 실행 권한을 보존합니다.
- 권한만 바뀐 스크립트도 업데이트 변경 사항으로 감지합니다.
- 실행 권한을 복원할 때 파일의 읽기 권한 범위를 넘지 않으며, 특수 권한은 적용하지 않습니다.

## 0.12.2 - 2026-09-25（中文）

修复导入或更新技能时保留可执行脚本权限的问题。

- 从 GitHub 导入或更新技能时保留文件的可执行权限。
- 将仅权限变化的脚本识别为更新内容。
- 恢复执行权限时不扩大文件读取权限，也不应用特殊权限位。
