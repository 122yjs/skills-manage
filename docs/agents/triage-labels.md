# 분류 라벨

엔지니어링 스킬은 다섯 가지 분류 역할로 말한다. 이 파일은 그 역할을 이 저장소 이슈 트래커의 실제 라벨 이름에 연결한다.

| mattpocock/skills의 역할 | 이 저장소의 라벨 | 뜻 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 관리자가 검토해야 함 |
| `needs-info` | `needs-info` | 보고자에게 추가 정보를 기다림 |
| `ready-for-agent` | `ready-for-agent` | 명세가 충분해 에이전트가 바로 맡을 수 있음 |
| `ready-for-human` | `ready-for-human` | 사람이 직접 구현해야 함 |
| `wontfix` | `wontfix` | 처리하지 않음 |

스킬이 역할 이름을 말하면(예: "에이전트가 맡을 수 있다는 분류 라벨을 붙여라") 이 표의 라벨 이름을 쓴다. 실제로 쓰는 라벨 이름이 바뀌면 둘째 열을 고친다.
