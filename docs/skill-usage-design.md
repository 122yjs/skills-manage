# 플랫폼 표시와 스킬 사용

## 사용자 동작

- 플랫폼 표시는 사이드바에서 볼 도구를 고르는 체크박스 설정이다. 전체 선택/전체 해제를 제공한다. 스캔과 사용 상태에는 영향이 없다.
- 스킬 사용 토글을 끄면 관리 중인 설치를 도구가 읽지 않는 저장소로 옮겨 보존한다. 다시 켜면 같은 파일과 설치 방식으로 복원한다. 사용 중지는 삭제나 30일 휴지통과 다르며 자동 만료하지 않는다.
- 플랫폼 전체 토글을 끄면 그때 사용 중이던 관리 설치만 중지한다. 다시 켜면 그 전체 중지로 멈춘 설치만 복원한다. 이전부터 개별 중지된 스킬은 켜지 않는다.
- 상태는 사용 중/일부 사용 중/중지/관리 가능한 스킬 없음으로 구분한다. 일부 상태에서 전체 토글을 누르면 사용 중인 항목들을 중지한다.
- 공용 설치는 독립된 제어 대상이다. 개별 플랫폼에서 공용 설치나 플러그인을 발견해도 그것을 함께 변경하지 않는다. 제어할 수 없는 출처가 남으면 별도 개수와 안내를 표시한다.
- 중지된 파일과 기록은 재시작 및 재스캔 뒤에도 남아야 한다. 원래 위치 충돌, 저장 실패, DB 실패 때 파일을 잃거나 다른 파일을 덮어쓰지 않는다.
- 현재 대화에 이미 읽힌 스킬 지시를 취소하는 기능은 아니다. 도구의 재로드/새 세션이 필요할 수 있음을 안내한다.

## 구현 경계

사용 중지 파일은 DB 옆 paused-installations 아래 보존한다. 기존 recovery 휴지통 만료 로직과 분리한다. 원본/설치 경로 검증, symlink 보존, DB 기록의 영속성, 실패 시 복구는 필수다. 플랫폼 표시용 agents.is_enabled는 그대로 사용하되 실제 사용 상태로 재해석하지 않는다.

백엔드 IPC 계약:
- get_skill_usage_status() -> UsageStatus[]
- set_skill_usage({skillId, agentId, enabled}) -> void
- set_platform_usage({agentId, enabled}) -> void

UsageStatus: agent_id, active_count, paused_count, external_count, skills: [{skill_id, name, enabled, paused_by_bulk}]. 관리 스킬만 skills에 담는다. external_count는 공용/플러그인 등 개별 제어 불가능한 관측 개수다. UI는 실패 시 서버 상태를 다시 읽고 부분 성공을 전체 성공으로 알리지 않는다.

전체 중지의 복원 대상은 영속 기록의 paused_by_bulk로 보존한다. 중지 레코드는 스캐너의 stale 정리에 휩쓸리지 않는다. 기존 설치/삭제/보관함 이동과 충돌하는 중지 상태는 명확히 거절하거나 안전하게 처리한다. 최소한의 처리로 원본 손실을 막는다.

## 조작 예시

| 현재 상태 | 조작 | 결과 |
|---|---|---|
| A 사용, B 개별 중지 | 플랫폼 전체 중지 | A만 전체 중지 대상으로 보존, B 유지 |
| A 전체 중지, B 개별 중지 | 이전 상태 복원 | A 사용, B 중지 유지 |
| 모두 개별 중지 | 플랫폼 전체 제어 | 복원 대상이 없음을 안내하고 개별 사용을 선택하도록 안내 |
| 전용 A 사용, 공용 A도 제공 | 전용 A 중지 | 전용 설치만 중지, 공용 출처가 남는다는 안내 |
| 플랫폼 숨김, A 사용 | 플랫폼 다시 표시 | A 사용 유지 |

관리 대상이 일부 사용 중이면 전체 제어는 사용 중인 관리 대상을 중지한다. 복원 대상이 없는 상태에 동작하지 않는 켜기 토글을 제공하지 않는다. 중지 보관소의 파일을 다른 스캔 경로가 다시 설치 대상으로 취급하지 않도록 보호한다.

## 검증

임시 파일 DB에서 개별 중지/복원, 수정한 복사본 보존, 심볼릭 링크 복원, 전체 복원 시 개별 중지 유지, 재스캔/재시작 유지, 충돌 거절, 실패 복구, 공용 출처 잔존을 검사한다. 프런트는 표시 체크박스와 사용 토글의 다른 IPC, 일부 상태, 전체 복원 동작을 검사한다.
