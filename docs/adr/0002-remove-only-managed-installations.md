# 앱은 관리 설치만 제거하고 관찰 항목은 보호한다

플랫폼 폴더에서 발견한 스킬 폴더는 보관함 원본과 내용이 같을 때만 관리 설치로 본다. 사용자가 직접 만들었거나, 원본과 내용이 다르거나, 비교할 수 없는 폴더는 관찰 항목으로 둔다. 관찰 항목은 목록에 보여 주기만 하고 제거·연쇄 삭제·플랫폼 전체 삭제·덮어쓰기 대상으로 삼지 않는다. 사용자가 가져오기를 하면 그 내용을 보관함 원본으로 복사하고, 플랫폼 폴더는 그대로 둔 채 관리 설치로 기록한다.

이렇게 정한 이유는 2026-11-15 평가 결과다. 스캐너가 사용자가 만든 폴더를 앱의 복사 설치로 기록하고, 제거나 연쇄 삭제가 그 폴더를 지우는 것이 확인되었다. "설치를 지워도 원본은 보관함에 남는다"는 약속을 지키려면 원본이 확보된 것만 관리해야 한다.

## Considered Options

- **기존 copy 기록을 모두 관찰 항목으로 낮추기**: 가장 안전하지만, 앱이 만든 복사 설치까지 다시 가져와야 제거할 수 있다.
- **기존 기록은 그대로 두고 새 스캔부터 적용**: 이미 섞여 있는 기록의 삭제 위험이 남는다.
- **가져오기 때 플랫폼 폴더를 보관함 링크로 바꾸기**: 원본이 한곳에 모이지만, 그 폴더를 직접 고치던 사용자의 작업 방식이 바뀐다.

## Consequences

- 업데이트할 때 기존 copy 기록을 보관함 원본과 한 번 비교해 다시 분류한다.
- 같은 이름의 다른 보관함 스킬이 있으면 가져오기가 자동으로 덮어쓰지 않고, 중복 출처 비교를 보여 준다.
