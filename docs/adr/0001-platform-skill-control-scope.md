# 플랫폼별 스킬 제어를 위한 설치 전환과 범위

모든 플랫폼에서 스킬별 사용 여부를 선택하는 목표를 위해, 플랫폼 자체의 제외 설정 외에 필요한 공용 스킬을 플랫폼별 설치로 전환하는 기능도 설계 범위에 포함한다. 기존 공용 설치를 무조건 유지하면 해당 플랫폼의 제외 기능에 지원 범위가 묶이기 때문이다. 이는 제품 설계 결정이며 사용자의 실제 설치를 지금 변경한다는 승인은 아니다.

프로젝트 복사본이나 플러그인 등 별도 출처가 남는 것은 허용하며, 모든 출처의 완전 차단을 완료 조건으로 요구하지 않는다. 별도 출처가 남을 수 있는 상태를 완전 차단으로 표현하지 않는다.

사용자가 우려하는 중복은 한 에이전트가 여러 저장소에 있는 동일한 스킬을 불필요하게 반복해서 읽는 경우다. 따라서 플랫폼별 사용 여부 선택과 함께, 동일 스킬의 여러 출처로 인한 불필요한 중복 로딩을 줄이는 것을 목표로 한다. 파일이 여러 곳에 남아 있는 것과 실제 대화에 같은 내용이 중복으로 들어가는 것은 구분하며, 파일 개수나 화면의 묶음 표시만으로 컨텍스트 절감을 주장하지 않는다.

내용까지 동일한 스킬은 해당 플랫폼에서 대표 출처 하나를 사용한다. 이름이 같아도 버전이나 내용이 다르면 차이를 보여주고 사용자가 사용할 출처를 선택한다. 이름만으로 자동 통합하지 않으며, 동일 여부를 확인할 수 없는 출처도 동일하다고 간주하지 않는다. 대표 출처 선택은 다른 저장소의 원본을 삭제하거나 서로 다른 내용을 합친다는 뜻이 아니다.

동일했던 출처 중 하나가 업데이트되어 내용이 달라지면 기존 대표 출처를 유지하고 다음 스캔에서 차이를 표시한다. 대표 출처를 자동으로 변경하거나 다른 복사본을 덮어쓰지 않는다. 선택한 출처 자체의 업데이트를 막거나 예전 버전으로 고정한다는 뜻은 아니다.

플랫폼별 설치로 전환한 스킬은 새로 추가한 플랫폼에 자동 설치하지 않는다. 사용자가 해당 플랫폼에서 명시적으로 켜도록 한다. 이 기본값은 앱이 수행하는 설치에 관한 것이며, 외부 도구가 독자적으로 발견하거나 설치한 출처까지 차단한다는 뜻은 아니다.

플랫폼마다 실제 제외 설정, 탐색 경로와 중복 처리 동작을 조사해야 한다. 현재 앱의 미지원 상태를 플랫폼 자체의 기능 부재로 해석하거나, 설치 전환만으로 모든 플랫폼의 독립 제어가 보장된다고 가정하지 않는다.

## 후속 명세와 검증의 기준

- 모든 등록 플랫폼을 조사 범위에 포함한다. OMP, AGY/Antigravity, CodeBuddy, Kiro, Cursor, OpenClaw만의 예외 구현으로 범위를 축소하지 않는다.
- 플랫폼별로 탐색 경로, 공식 제외 기능, 동일 스킬의 중복 처리, 변경 반영 시점을 확인하고 근거를 남긴다. 조사 결과에 따라 설정 변경 또는 설치 전환 방식을 정한다.
- 플랫폼 A의 사용 여부나 대표 출처를 바꿔도 플랫폼 B의 사용 상태와 저장소 원본을 보존한다. 설치 전환은 영향 범위 확인과 복원을 지원한다.
- 앱의 목록을 묶은 결과, 실제 설치 경로를 정리한 결과, 에이전트의 스킬 목록이나 로딩을 검증한 결과를 구분한다. 기존 대화에 이미 들어간 내용을 제거했다거나 에이전트의 모든 반복 읽기를 막았다고 주장하지 않는다.
- 별도 출처가 남아 있는 경우 이를 표시하며, 확인하지 못한 플랫폼에서 중복 로딩 방지나 컨텍스트 절감이 검증됐다고 표시하지 않는다.

위 항목은 설계 인터뷰에서 합의한 제품 정책과 후속 검증 기준이다. 기능 구현, 실제 설치 전환, 커밋 및 배포는 아직 수행하지 않았다.
