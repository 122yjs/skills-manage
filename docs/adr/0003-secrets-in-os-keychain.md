# 비밀값은 OS 키체인에만 저장한다

AI API 키와 GitHub 토큰은 OS 키체인(macOS 키체인, Windows 자격 증명 관리자, Linux Secret Service)에만 저장하고, SQLite에는 설정 여부만 남긴다. 기존 DB와 복구용 DB 백업에 평문으로 남은 비밀값은 키체인으로 옮긴 뒤 그 칸만 지운다. 백업 파일 자체는 유지한다. 키체인을 쓸 수 없는 환경에서는 평문으로 저장하지 않고 실행 중 메모리에만 두며, 그 이유를 화면에 안내한다.

이렇게 정한 이유는 DB 파일과 만료 없는 DB 백업이 복사·공유·동기화되기 쉬워서다. 그러면 비밀값이 사용자가 의도한 것보다 오래 남는다.

## Considered Options

- **DB에 그대로 두고 화면 노출만 막기**: 단순하지만, 설정에서 지운 키도 DB 백업에는 계속 남는다.
- **키체인을 못 쓰는 환경에서는 평문 저장으로 대체**: 편하지만, 그 환경에서는 보호가 사라진다.

## Consequences

- OS 키체인에 접근하는 라이브러리가 새 의존성으로 들어온다.
- 웹 대시보드는 비밀값을 읽지 않고 설정 여부만 보여 준다.
- 키체인이 없는 Linux에서는 앱을 다시 켤 때마다 비밀값을 다시 입력해야 한다.
